# 🕯️ Illumination by Gargi — Luxury Botanical Soy & Beeswax Candle Store

An ultra-luxurious, state-of-the-art e-commerce web application for **Illumination by Gargi**, showcasing handcrafted botanical candles, whispering crackle wood wicks, custom candle labeling, and interactive scent finder quizzes.

---

## 🌟 Key Features

- **Luxury Boutique Aesthetics**: Rich deep amber gold palette (`#B45309`), glassmorphism UI components, and ambient flickering flame motion animations.
- **100% Authentic Candle Catalog**: High-resolution studio photography featuring custom-branded candle jars (*"ILLUMINATION BY GARGI"*).
- **Interactive Scent Quiz**: Personalized fragrance recommendation wizard matching customer scent profiles (Warm Vanilla, French Lavender, Smoked Oudh, Bergamot).
- **Live VIP Launch Countdown Banner**: Real-time dynamic countdown clock (`DAYS`, `HOURS`, `MINS`, `SECS`) computed from real system time (`new Date()`).
- **Responsive Navigation**: Adaptive header matrix for Mobile, Tablet, and Desktop screens with crisp compact rectangular action buttons and cart badges.
- **Shopping Cart & Checkout**: Slide-over cart drawer with real-time price calculation, coupon code discount support, and full order summary.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS3 Design Tokens + Tailwind CSS v4
- **Icons**: [Lucide React](https://lucide.dev/) Vector Icons
- **Fonts**: Google Fonts (Cinzel / Playfair Display / Inter)

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/badalvarshney/Candle-Market.git
cd Candle-Market
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 4. Build for Production
```bash
npm run build
```
